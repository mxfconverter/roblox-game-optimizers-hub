## 📦 Features & Code Models Included

### 1. Build A Ring Farm (Grow a Garden) Revenue Formula
Our algorithm simulates the complex mathematical formula of the game:
$$\text{Expected Profit} = \text{Base Income} \times (1 + \text{Level} \times 0.15) \times \text{Ring Multiplier} \times \text{Saw Multiplier} \times \text{Mutation Multiplier} - \text{Seed Cost}$$

### 2. Wizard Alchemy Race Reroll Gacha Math
A Python-based model evaluating cumulative probability and gold cost required to pull 1% rare races (like Thestrals) over N attempts.

## 🛠️ Installation & Usage
To run the local terminal calculators:
1. Clone this repository:
   ```bash
   git clone https://github.com/mxfconverter/roblox-game-optimizers-hub.git
   ```
2. Navigate into the repository:
   ```bash
   cd roblox-game-optimizers-hub
   ```
3. Run the Build A Ring Farm crop analyzer:
   ```bash
   python grow_a_garden/crop_calculator.py
   ```
4. Run the Wizard Alchemy race simulator:
   ```bash
   python wizard_alchemy/race_simulator.py
   ```
